Unblock Banned Servers is a client-side Minecraft mod that allows players to connect to servers listed on Mojang's blocked server list. It changes the client's hostname check so that connections to these servers are no longer automatically rejected.

The mod does not modify server software, require server-side installation, or include Minecraft game files. It is intended for players who want more control over which servers they choose to connect to.

Only players who install the mod need it. All other multiplayer functionality works as usual.
